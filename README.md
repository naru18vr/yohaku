# yohaku

**何もしないための3分間。**

疲れた時に、1分だけでも静かに休むための、小さな瞑想タイマーです。
記録や評価、続けることを促す通知はありません。呼吸は、自分のペースで。

[休む画面を開く](https://naru18vr.github.io/yohaku/)

## Features

- 1・3・5・10分。初回は3分を1タップで開始
- 吸う4秒 → 少し止める2秒 → 吐く6秒の、穏やかな呼吸の円
- 一時停止・再開・途中終了、残り時間の表示／非表示
- 無音・雨・波。つなぎ目でも音の密度を保つ、連続した環境音
- 目を閉じて使える、任意の呼吸音ガイド（初回はOFF）
- 音量調整と、任意の終了ベル（初回は無音・ベルOFF）
- 端末に合わせた明暗テーマ、明るめ／暗めの手動選択
- キーボード操作、フォーカス表示、読み上げ用の開始／停止／終了通知
- `prefers-reduced-motion: reduce` では円を静止
- ホーム画面用アイコンとWeb App Manifest
- ビルド不要、ライブラリ不要、外部バックエンド不要

このアプリは「少し休むためのWebアプリ」です。医療的な効果をうたうものではありません。

## How to use

1. ページを開いて「3分休む」を押します。必要なら、先に時間を選びます。
2. 円を眺めても、目を閉じても大丈夫です。呼吸を円に合わせる必要はありません。
3. 時間が過ぎると「おつかれさま。」の画面になります。「終わる」で最初の画面へ戻れます。

「音 · 無音」から、雨／波・呼吸の音ガイド・音量・終了ベル・画面の明るさを変更できます。
音は開始ボタンを押した後だけ流れます。無音を選んでも、ベルを自分でONにした場合は終了時に一度だけ鳴ります。
音量0では、環境音・呼吸ガイド・ベルのすべてが無音になります。

目を閉じて呼吸の目安がほしい時は、「呼吸の音ガイド」をONにします。
小さな音が4秒かけて高くなり、2秒の静かな間の後、6秒かけて低くなります。
高くなる音が「吸う」、低くなる音が「吐く」の目安です。合わせずに自然に呼吸しても大丈夫です。
雨や波と一緒にも、ガイドだけでも使えます。一時停止後は、停止した呼吸の位相から再開します。
ガイドがONの時は、音設定ボタンにも「呼吸ガイド」または「雨・ガイド」「波・ガイド」と表示します。

タイマーの数字を押すと残り時間を隠せます。「時間を表示」で戻せます。
一時停止中は時間が減りません。「ここで終わる」は、確認画面なしですぐに終了します。

時間・環境音・呼吸ガイド・音量・ベル・テーマは `localStorage` に保存します。履歴や利用回数は保存しません。
保存が許可されない環境でも利用できます。設定をリセットするには、このサイトのブラウザデータを削除してください。

## Run locally

`index.html` を直接開くだけで、タイマーと合成音を使えます。
ホーム画面関連の機能はHTTP/HTTPSで利用してください。

HTTPで確認する場合は、リポジトリのルートで実行します。

```sh
python -m http.server 8000
```

[http://localhost:8000](http://localhost:8000) を開きます。終了は `Ctrl+C`。
Node.js、npm、ビルド処理は、アプリの利用・公開には必要ありません。

## Deploy to GitHub Pages

ファイルを **`main` ブランチのルート**に置いた状態で公開できます。独自のGitHub Actionsワークフローは不要です。

1. [リポジトリ](https://github.com/naru18vr/yohaku) の **Settings → Pages** を開きます。
2. **Build and deployment → Source → Deploy from a branch** を選びます。
3. **Branch → main → / (root)** を選び、**Save** を押します。
4. GitHubの公開処理が終わったら、Pages画面に表示されるURLを開きます。

公開先は [https://naru18vr.github.io/yohaku/](https://naru18vr.github.io/yohaku/) です。このリポジトリではPagesを有効にして公開済みです。
CSS・JavaScript・アイコン・Manifestは相対パスなので、`/yohaku/` の下でも動きます。
`.nojekyll` でJekyllの処理を省きます。GitHubが用意するPagesのデプロイ処理自体は実行されます。
更新時は`index.html`のCSS・JavaScript URLと`tests/responsive.html`のフレームURLの`v`を更新し、ブラウザに新しいファイルを読み込ませます。

別のリポジトリや独自ドメインで公開する場合は、`index.html` の canonical、`og:url`、`og:image` を公開URLに変更してください。
HTTPSはGitHub Pages側で設定します。

[GitHub公式の公開元設定ガイド](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

雨には、この会話で提供された10分の録音音源を使います。波・呼吸ガイド・ベルはWeb Audio APIでその場で合成します。外部の音声素材・MP3・フォント・画像サービスへのアクセスはありません。

波は柔らかなノイズから作る環境音です。ガイドは穏やかな正弦波の高さを変えた音、ベルは小さな正弦波を重ねた音です。

## Timer and sound

残り時間は `終了予定時刻 − Date.now()` で計算します。更新の回数は時間の基準にしません。
画面更新が遅れても、次の更新やタブへの復帰時に時刻へ同期します。
時計が巻き戻っても、表示上の残り時間や呼吸の位相が逆行することはありません。
一時停止時に残り時間を保存し、再開時に終了予定時刻を組み直します。
呼吸の位相も、実際に経過した休息時間から計算します。

波と雨の代替音は20秒のステレオノイズを使い、末尾に続くノイズを先頭へ等電力で重ねてつなぎます。
つなぎ目を平らな波形へ寄せる処理を廃止し、周期的な音の落ち込みを抑えています。
波のゆっくりした強弱も、音が消えたように感じにくい深さに調整しています。
環境音とガイドのループ再生はWeb Audioが担い、画面更新の回数を再生の基準にしません。
ガイドは円と同じ12秒周期です。再開・設定変更・音声中断からの復帰時は、現在の呼吸の位相へ合わせます。
通常の画面復帰や音量・ベル変更で、環境音とガイドを不要に再生成しません。
ガイドの終了もAudioContext上に予約するため、画面更新が遅れても終了後に案内を続けません。

[AudioBufferSourceNodeの再生・開始位置の説明（MDN）](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode/start)

ベルはユーザーが許可したAudioContext上で、終了予定時刻に一度だけ予約します。
一時停止・途中終了・音設定の変更時には古い音の予約を取り消します。
音の準備が終わる前に終了した場合にも、遅れて音が流れないようにしています。
音声の中断・画面への復帰時には、ガイドの位相とベルを現在の残り時間に合わせ直します。期限後の遅いベルは取り消します。
ベルの余韻と環境音のフェードアウト後は音声ノードを解放し、AudioContextを休止します。

ブラウザ・OSは、画面ロック、省電力、別アプリの音声、バックグラウンド状態で音やJavaScriptを止めることがあります。
その場合は復帰後に残り時間と終了画面を同期しますが、画面ロック中のベルや環境音の継続は保証できません。
音が中断した時は「音を再開」から再試行できます。再生できなくても無音で休めます。
端末の時計を手動変更すると終了時刻に影響します。ページを再読み込みすると進行中の時間はリセットされます。

Manifestとアイコンによるホーム画面への追加を用意しています。Service Workerは使わず、オフラインキャッシュや通知、インストールを促す画面はありません。

## Privacy

ログイン、利用履歴、広告、アクセス解析、外部へのユーザー情報の送信はありません。
設定はこのサイトのブラウザ内にだけ保存します。アプリがAPIや外部CDNへ通信することはありません。
GitHub Pagesで公開する場合のページ配信はGitHubによって行われます。

## Testing

ロジックの自動テストは、Node.js 18以上があれば依存パッケージなしで実行できます。

```sh
node --test tests/app.test.cjs
```

テスト対象は4つの時間、遅延したタイマー更新、一時停止・再開・終了、呼吸の位相、音の切り替え、音量、ベルの予約と取り消し、音声中断からの復帰、音声時計の停止、呼吸ガイドの音の高さ・無音の間・位相・終了予約、環境音のつなぎ目の密度、ノードの解放と休止、音声エラー、非同期の音声準備中の終了、設定の保存不可・破損、reduced motionです。
DOMとWeb Audioの最小スタブを使うロジックテストであり、実ブラウザや実際の音の聴感の検証を置き換えるものではありません。

HTTPで起動した後、[表示確認ページ](tests/responsive.html)で320・375・390・412pxの縦画面、568・844pxの横画面、1024pxのデスクトップ表示を並べて確認できます。各フレームで通常のアプリを操作します。確認用ページはアプリの初回読み込みには含まれません。

実ブラウザでは、次を確認してください。

- iPhone Safari、Android Chrome、PC Chromeで、初回の1タップ開始と音の許可
- 320px・375px・390px・412pxの縦画面、長い端末、横画面、デスクトップ、拡大表示
- 雨・波の切り替えと連続性、音量0、ベルON/OFF、休息中の設定変更
- 呼吸ガイドの高い音／低い音、2秒の静かな間、雨・波との併用、途中からのONと一時停止後の再開
- タブを離れて戻る、一時停止後の再開、終了画面から再スタート
- `Tab`・矢印キー・`Space`・`Enter`、設定ダイアログの `Escape` とフォーカス復帰
- ダークテーマ、reduced motion、VoiceOver／TalkBackの画面読み上げ

2026-10-04に、GitHub Pagesの公開版をPC Chromeで確認しました。1分・3分の実時間での終了、4種類の時間の開始、一時停止・再開、音設定、明暗表示、キーボード操作、アプリ由来のコンソールエラーがないことを確認しています。再レビュー後は、7種類のフレームサイズでホーム・休息・終了・設定画面を操作し、横方向のはみ出しや操作ボタンの位置も確認しました。
iPhone Safari／Android Chromeの実機、VoiceOver／TalkBack、音の聴感は未確認です。フレームによる描画確認は実機検証とは区別しています。確認範囲とスクリーンショットは、[検証記録](VERIFICATION.md)に記載しています。
